# Food Reviews Sentiment Analysis 🍔📊

This project performs sentiment analysis on food reviews using Natural Language Processing (NLP).

## 📌 Project Overview
Customer reviews are analyzed and classified into:
- Positive
- Negative
- Neutral

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- TextBlob (NLP)

## 📂 Dataset
- Reviews.csv (Food product reviews)

## ⚙️ How It Works
1. Load the dataset
2. Clean and process text data
3. Apply TextBlob sentiment polarity
4. Classify sentiments
5. Visualize sentiment distribution

## 📊 Output
- Bar chart showing sentiment counts
- Majority of reviews are **Positive**
